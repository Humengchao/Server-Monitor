# AI 服务器助手

Web 侧栏的“AI 助手”可使用你自己的 DeepSeek、OpenAI、通义千问、Moonshot、智谱、SiliconFlow、Gemini 或兼容 Chat Completions / Function Calling 的模型，
对当前账号拥有的服务器执行任务。服务器详情页也提供入口，会预选该服务器。
SSH 与 Linux / Windows Agent 使用相同执行通道；远端操作权限由服务器的连接账户决定。

## 配置与开始

1. 打开“AI 助手 → 提供商设置”，选择供应商预设，填写服务名称、API 地址和 API Key。
   DeepSeek 预设为 `https://api.deepseek.com` 和 `deepseek-flash`，可按账号可用模型修改。
   CPA 或其他反代选“CPA / 兼容 API”，填写其 HTTPS 基础地址，例如 `https://model.example.com/v1`，应用追加 `/chat/completions`。
   点击获取模型可在保存前读取目录；已保存配置在打开编辑时及页面可见期间每五分钟自动刷新。模型目录来自该配置的 `/models`，不代表账号拥有全部模型权限。
   若供应商不支持兼容目录接口，页面提示后仍可手动填写模型 ID。接口与地区地址说明见 [提供商文档](ai-provider.md)。
2. 保存后可点击“测试”。测试会真实调用一次该提供商，可能产生该提供商的费用。
3. 选择一台服务器和一个已启用的模型配置、审批等级，以及需要的 Skill / 插件，输入任务，例如“安装并启动 Nginx，并检查版本和服务状态”。
4. 提交后后台开始执行；页面展示对话、每一步工具、具体命令或文件内容、输出、退出码及 token 用量。
   离开页面不会停止任务，回来可从任务记录继续查看。已完成任务可追加问题。
   助手消息支持 Markdown 表格、列表及代码块复制；执行命令、文件内容和审批参数始终按原文展示。远程图片与原始 HTML 不会自动加载。
   工作区固定在一屏内，输入框与任务信息始终可见；长对话、历史列表和展开后的命令输出在各自区域内滚动，隐藏可见滚动条。消息区可聚焦后使用键盘滚动；手机上的历史记录从“任务历史”抽屉打开。

服务器选择决定实际执行目标；任务文字中的其他服务器名称不会扩大授权范围。
新 Agent 需要先完成登记。没有足够系统权限时，AI 不会自动获得 root 或管理员身份。

## 自动执行与确认

新任务默认使用“标准”，每个任务的审批等级创建后固定，补充消息不能提高权限。

| 等级 | 行为 |
| --- | --- |
| 只读 `readonly` | 仅允许经过检查的诊断与普通文本读取；拒绝安装、修改、未知命令及 MCP 工具调用。 |
| 标准 `standard` | 常规操作直接执行；高风险、未知命令和 MCP 工具调用需要对具体内容确认。 |
| 完全自动 `automatic` | 用户明确选择后，在所选服务器、插件和任务目标范围内直接执行，包括高风险操作，无需逐项批准。 |

以下审批说明适用于标准模式。明确提交任务后，常规检查、严格参数化的软件包安装和常规服务操作直接执行。
删除、卸载、格式化、重装、停止关键服务、安全与启动配置修改，以及无法可靠解释的脚本或命令，
会停在“等待确认”。应用使用服务端规则判定，模型不能通过自行声明“安全”跳过确认。

确认界面显示服务器、动作、命令或文件内容及原因。批准只适用于这一个已保存的动作；拒绝会停止任务。
审批前后服务器连接配置或模型配置发生变化时，旧任务会停止，需针对新配置重新下达任务。
为了让确认内容可检查，暂不自动执行任意 shell 程序：复杂安装脚本、Docker Compose、未知配置格式等可能需要确认。

内置工具包括系统检查、仓库软件包安装、服务管理、文本读取/修改及命令执行。
文件修改要求版本校验；覆盖前创建备份。SSH 私钥、密码数据库和常见秘密文件禁止由文件工具读取到模型上下文。
文本修改的自动执行范围目前较窄，主要是识别出的 Nginx 声明式配置；其他文件会请求确认。
完全自动模式仍保留凭据过滤、目标身份校验、文件版本校验、操作日志和未知结果不重试规则，不会自动提升操作系统账号权限。

## Skills 与 MCP 插件

在“Skills / 插件”中新增 Skill，可直接编辑 Markdown 或导入本地 `.md` / `.markdown` 文本。每账号最多 50 个 Skill，单份最多 32 KiB；每任务最多选 8 个，总内容最多 96 KiB。
选中的内容在创建任务时保存快照，后续修改 Skill 只影响新任务。Skill 提供工作流程指导，不能扩大服务器范围或改变审批等级。

MCP 插件填写完整的 **Streamable HTTP HTTPS 地址**（例如 `https://tools.example.com/mcp`），可配置 Bearer token。Token 加密保存且不回传浏览器；留空保留，清除需要显式选择。改变 URL 时需要重新输入 token 或明确清除旧 token。
“测试”只执行 MCP 初始化和工具列表读取，不执行远程工具。每账号最多 10 个插件，每任务最多选 4 个；单插件最多 32 个工具，合并内置工具后最多 96 个，超限会提示减少所选插件。

任务只可调用所选插件提供的工具。标准模式逐项展示插件地址、工具名与完整参数等待审批；只读模式不提供插件调用；完全自动按已选权限执行。插件运行于外部服务，其能力由该服务及配置的 token 决定，可能操作服务器以外的系统，请只选择本次任务需要的插件。
执行前重新检查插件配置和工具定义；变更后旧审批停止。调用超时或连接断开导致结果不确定时，不自动重试。

初版支持 MCP `2025-03-26`、`2025-06-18`、`2025-11-25` 的 POST JSON / SSE 响应、会话头及工具分页；不运行本地 stdio 插件，不下载插件程序，不支持旧版独立 SSE 端点、采样回调、后台订阅或远程图片/资源抓取。单次操作最多 90 秒，响应最多 2 MiB，文本结果按任务输出上限截断。

## 中断、记录和边界

- 每账号最多两个活动任务，同一服务器同时只能有一个活动任务；后台每实例最多执行两个任务。
- 每任务最多 24 次模型步骤，每段运行最多 20 分钟；单条命令最多 5 分钟。
- 单步输出最多保留 64 KiB，送回模型的输出最多 24 KiB；文本文件工具最多处理 24 KiB。
- 请求使用幂等 ID，重复提交同一请求不会重复创建或继续任务。命令开始前先写入动作记录。
- 点击停止会取消模型请求及当前远程会话。已经完成的操作不会自动回滚；普通 SSH 上的脱离会话进程可能继续运行。
- 网络断开或后台重启导致执行结果不明确时，任务标记为中断/失败，不自动重放该命令。
  请先检查服务器状态，再决定是否创建新任务。
- 数据库保留任务、事件、动作及审批记录。AI 不能把网页内容或命令输出作为新的授权指令。

## 密钥与发送的数据

API Key 使用当前实例的 `ENCRYPTION_KEY` 加密存储，只由后端调用模型，页面只显示“已保存密钥”。
编辑时密钥留空会保留原值；修改 API 地址时必须重新填写密钥，防止旧密钥自动发往另一个地址。
模型 API 请求通过 HTTPS 验证证书，不跟随重定向；默认拒绝回环、私网和特殊地址。
自建私网 HTTPS 模型可由部署者显式设置 `AI_ALLOW_PRIVATE_ENDPOINTS=true`，与通知 Webhook 配置独立。

任务内容、所选服务器的名称/系统/运行身份，以及操作产生的命令输出或读取的文件内容，会发送给你选择的模型服务。
不要在任务中粘贴秘密；新任务和补充消息若包含已知连接密码、模型密钥、私钥或可识别的凭据内容，会直接拒绝，不保存或发送给模型。
应用也对已知密钥和私钥输出做脱敏，但任意远端输出可能仍含业务数据。
提供商测试与任务的实际费用由你的模型服务收取，本面板只展示 token 数量，不估算货币费用。

当前配置备份不包含 AI 提供商密钥、Skills、MCP 插件、AI 任务或执行记录；迁移后需重新配置 AI。
模型接入细节见 [提供商说明](ai-provider.md)。

官方协议参考：[DeepSeek Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)、
[DeepSeek Tool Calls](https://api-docs.deepseek.com/guides/tool_calls/)。

## 任务 API

全部接口要求登录，仅访问当前用户拥有的任务；任务和动作 ID 都参与审批校验。

| 方法与路径 | 请求或响应 |
| --- | --- |
| `POST /api/ai/tasks` | `{server_id,provider_id,prompt,request_id,approval_mode?,skill_ids?,plugin_ids?}`；202 返回任务，`request_id` 为客户端生成的 UUID；缺省审批等级为 `standard` |
| `GET /api/ai/tasks?limit=30&before=...` | `{tasks,next_cursor}`；`before` 使用上一页返回的不透明游标，最多 50 条 |
| `GET /api/ai/tasks/:id` | `{task,events,actions}`；不返回内部模型会话、reasoning 或连接指纹 |
| `POST /api/ai/tasks/:id/cancel` | 返回任务；正在执行时先进入 `cancel_requested` |
| `POST /api/ai/tasks/:id/messages` | `{message,request_id}`；仅已完成或等待输入的任务可继续 |
| `POST /api/ai/tasks/:id/actions/:action_id/decision` | `{decision:"approve"}` 或 `{decision:"reject"}`；不接受替换命令或其他参数 |

任务说明和补充消息最多 16,000 UTF-8 字节。中断或执行结果不明的任务不能直接续跑。
审批、取消与执行开始均通过数据库状态比较处理；失败或重复决策返回冲突，客户端需刷新当前状态。
同一个新任务请求 ID 只能重试相同的服务器、模型配置和任务文本；变更内容必须使用新的 ID，否则返回冲突。
审批等级和所选扩展 ID 同样参与幂等校验。任务返回 `approval_mode`、`skills:[{id,name}]`、`plugins:[{id,name}]`，不返回内部指纹或 Skill 内容快照。
补充消息同样绑定请求 ID 和内容摘要；已受理的重试只返回原任务，即使模型配置或服务器随后变化，也不会重新执行。
模型返回无效工具参数不会额外消耗模型步骤。对话达到容量上限后会停止任务，已经完成的操作仍保留真实结果。

扩展接口均要求登录并校验账号所有权：`GET/POST /api/ai/skills`、`GET/PUT/DELETE /api/ai/skills/:id`；`GET/POST /api/ai/plugins`、`PUT/DELETE /api/ai/plugins/:id`、`POST /api/ai/plugins/:id/test`、`GET /api/ai/plugins/:id/tools`。没有绕过任务审批直接调用工具的 HTTP 接口。

更新提供商、Skill 或插件时，必须发送编辑时取得的 `expected_updated_at`；缺失或旧版本返回 409。创建不需要版本。任务达到步数或上下文容量上限时也返回明确的 409，不会进入“提交结果未知”；已受理请求的重试仍只返回原任务。响应丢失后的恢复请求遇到 429/408 时保留原请求 ID，等待后重试。

MCP 工具调用在工具列表、初始化和 DNS 等等待结束后再次检查配置、任务、动作及租约；取消或撤权后不会发起新的工具调用。已开始的外部操作无法撤回。`nginx -t` 可能创建配置引用的日志文件，因此只读模式不执行它；标准和完全自动仍可直接执行此检查。Docker 诊断只返回明确选择的状态列，不自动传回容器启动参数。
