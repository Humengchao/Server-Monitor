# Web 配置备份与恢复

侧栏“备份恢复”用于导出当前账号的配置，并在同一或另一套 Server Monitor 中恢复。
备份文件为 `.smbak`，使用单独的备份密码加密，不依赖源实例的 `ENCRYPTION_KEY`。
这是配置迁移功能；历史指标和远端文件需要各自的备份方案。

## 包含与不包含的内容

| 包含 | 说明 |
| --- | --- |
| 服务器配置 | 名称、地址、系统/接入方式、备注、计费、到期时间、标签关联等 |
| 集中凭据 | 凭据名称、用户、类型；是否包含密码/私钥由导出选项决定 |
| 标签与告警规则 | 规则关联的服务器和通知渠道会在恢复时重新映射 |
| 通知渠道 | 类型与配置；可选择携带渠道密钥等敏感字段 |
| 网络检查 | 来源/目标关联、包数和阈值配置；不包含探测历史 |

不包含指标历史、告警事件/待投递队列、网络采样历史、远端文件、系统或容器日志、账号密码和登录会话，
也不包含 Agent 长期令牌、Agent 主机私钥或登记票据。恢复后 Agent 需要重新登记。

“包含 SSH 凭据和通知渠道密钥”默认勾选。取消勾选后仍保留相关配置记录，恢复时会提示补齐缺失密钥；
旧规则中可能携带密钥的直接 Webhook URL 也不会随无凭据备份导出。

## 导出

1. 打开“备份恢复”，输入**当前账号密码**以验证操作者身份。
2. 输入单独的备份密码，至少 12 位；按需选择是否包含凭据。
3. 点击“导出加密备份”，保存下载的 `.smbak` 文件，并单独保管备份密码。

文件在后端以 Argon2id 派生密钥，再用 AES-256-GCM 加密并验证完整性。
格式携带随机盐和 nonce；备份密码不会写入文件或配置数据库。
没有正确备份密码，就无法通过面板恢复其中的凭据。文件仍包含你选择导出的配置，勿只依赖文件扩展名判断是否适合分享。

当前格式版本为 1。未加密配置最大 **16 MiB**，加密文件另有 61 字节头部/认证开销。
浏览器在读取前拒绝超过 17 MiB 的文件，后端继续执行更严格的格式和大小校验。
备份密码的后端限制是 12–1024 个 UTF-8 字节；界面同时要求至少 12 个字符。

## 预览与恢复

1. 在目标面板登录要接收这些配置的账号，输入该账号的当前密码和导出时使用的备份密码。
2. 选择 `.smbak` 文件，点击“预览恢复”。预览显示服务器名称、各类记录数量、需要重新登记的 Agent 数量，
   以及是否包含凭据、是否已经导入。
3. 核对预览后点击“恢复此备份”，在确认框再次确认。

预览绑定所选文件的摘要。更换文件、当前账号密码或备份密码后，界面会清除预览并要求重新预览。
同一 `backup_id` 在同一目标账号只能成功恢复一次；如果预览后已被另一会话导入，恢复返回冲突，界面不会自动重试。

恢复在一个数据库事务中完成，失败时不保留半套配置。服务器、凭据、告警、通知渠道与网络检查均使用新 ID，
所属账号由当前登录身份决定，不沿用备份文件的用户身份。关联关系按新 ID 重建。
同名标签会复用目标账号已有标签，保留其现有颜色；其他同名记录作为新记录创建，不覆盖已有服务器或凭据。

## 恢复后的默认状态

所有导入的服务器均为**私有**，以下自动动作保持暂停：

- 主机监控采集。
- 自动顺延到期日期。
- 告警规则。
- 通知渠道。
- 网络检查。

无论备份前这些开关是否开启，恢复都不会直接连接整批主机、发通知或公开服务器名称。
这也意味着恢复后的指标暂时为空，不应把“待采集”理解为机器关机。

建议按以下顺序启用：核对主机地址与凭据；为 Agent 主机重新登记；检查通知渠道并发送测试；启用所需采集、
网络检查和告警；最后明确选择哪些服务器显示在公开状态页。
自动到期日顺延也需在服务器编辑表单中按需重新开启。

Agent 的重新登记命令须从**目标面板恢复后的服务器详情**生成。旧 Agent 的令牌仍绑定原面板/原服务器身份，
不会被备份迁移。具体安装、撤销和卸载步骤见 [Agent 指南](agent.md)。

## 跨实例与故障处理

恢复不要求源、目标实例使用相同的数据库加密密钥。包含的 SSH 和通知密钥会先从备份解密，再使用目标实例的
`ENCRYPTION_KEY` 加密落库。备份文件没有历史指标，也不能用于恢复整个数据库、账号体系或部署环境变量。

密码错误或文件损坏会拒绝恢复；当前账号密码错误、文件过大或重复导入会给出相应提示。
导出接口即使以二进制方式请求，失败时的 JSON 错误也会显示在页面中。
网络中断导致结果不明确时，先重新预览同一文件确认是否已导入，再决定是否重试；无需也不应手工改备份 ID。

后端记录导出/恢复审计信息，审计中不保存明文凭据。配置导出与恢复接口均需要登录、当前账号密码，
并有请求大小、并发和频率限制。
