# 新增功能复查与修复（2026-10-19）

本轮重点检查 Web AI 助手，并检查其依赖的 SSH / Linux 与 Windows Agent，以及网络监测、日志、通知、文件管理、备份、公开状态和到期顺延。

## 检查方法

1. 分别审查前端交互、模型接入、任务状态机、执行工具；用失败用例确认问题后修复。
2. 交换范围复查，增加响应丢失、配置并发修改、嵌套 JSON、Agent 运行身份变化和安装失败场景。
3. 独立复核合并结果，再执行后端完整测试、静态检查、前端完整浏览器回归及 CI 的 Linux 并发检查和跨系统安装测试。

## 修复内容

| 范围 | 问题与修复 |
| --- | --- |
| AI 目标选择 | SPA 内切换服务器时同步目标；模型停用或删除后要求重新选择，不把草稿自动交给另一提供商。 |
| AI 提交与补充 | 按工作区保留响应丢失的请求及原提供商；解除提交锁后刷新事件。同一请求 ID 绑定内容，异内容返回冲突；已受理补充请求在配置改变后仍可找回既有结果。 |
| AI 执行记录 | 无效参数不再额外计算模型步骤；上下文达到容量上限时先保存已完成操作的真实结果，再停止任务。 |
| 模型协议 | 拒绝重复字段、歧义大小写字段、NUL 和过深 JSON，防止截断响应被覆盖为工具调用。取消请求同时终止拨号和 TLS 握手。 |
| 模型配置 | 使用版本比较保护读取后保存，避免慢请求覆盖已更新的密钥或重新启用刚停用的配置。 |
| 凭据保护 | 拒绝包含已知凭据的新任务和补充消息；扫描嵌套 JSON 字符串及重复字段，阻止转义内容进入模型和执行记录；补齐 Docker 凭据、密码库备份等敏感路径。 |
| 配置修改 | Nginx 自动修改检查静态路径、完整语法边界及原配置，防止路径回退、动态路径或删除原有安全限制绕过审批。 |
| 软件安装 | APT 禁止找不到包名时回退到非锚定正则；Chocolatey 的 3010 记录为安装成功且需要重启，不自动重启。 |
| 文件写入 | SFTP 已提交写入却丢失成功响应时标为结果未知，停止任务，避免模型重复写入。 |
| Agent 身份 | 服务上线后同步实际运行账号和系统；AI 连接同时核验登记密钥、账号和系统，旧审批不能用于变更后的身份。 |
| Agent 安装 | 成功重新登记会撤销旧身份；后续安装失败保留新配置，只回退程序与服务，并显示恢复提示。 |
| 日志与网络页面 | URL 切换服务器时同步来源、选择和查询，取消旧请求，不继续读取上一台服务器。 |
| 通知页面 | 离开页面时关闭删除确认；卸载后的回调不能再删除旧渠道。 |
| AI 窄屏展示 | 长服务器名、模型名及提供商名称正常换行，审批上下文和设置操作不会被挤出屏幕。 |

## 验证范围与限制

本地完整验收：`go test ./...`（真实隔离 PostgreSQL）、`go vet ./...`、前端 build / lint 均通过；Playwright **134 项通过、1 项生产就绪检查本地跳过**。CI 继续执行 Linux `-race`、安装生命周期及生产浏览器检查，结果见对应提交的 Actions。

- 后端测试使用独立 PostgreSQL schema、本地 TLS / SSH / SFTP 服务和 PowerShell 模拟程序；覆盖所有权、并发、审批、取消、结果未知及凭据处理。
- Windows 安装测试只使用临时目录、模拟下载和模拟服务；Linux 安装生命周期由 CI 的隔离 Ubuntu 容器验证。
- 浏览器测试使用模拟业务 API；生产验收加载真实前端资源并检查后端就绪接口。
- 未使用真实模型密钥、调用付费模型、发送真实通知，或在用户服务器上安装软件。具体模型账号、网络和远端权限仍需实际使用时确认。
- 备份、公开状态、到期顺延和文件管理保留原有行为；其现有回归纳入完整测试。AI 配置及任务记录仍不包含在配置备份内，详见 [AI 文档](ai.md)。

## AI 扩展上线后的再次复查

本轮以 `bfe5a80` 为基线，分功能首审、前后端交叉审查、合并后独立复核三轮进行。新增问题先使用浏览器、真实 PostgreSQL 或本地 TLS / SSH / SFTP 复现，再补修复。

- 模型目录绑定密钥草稿，密钥变化清空目录并取消旧请求；禁止目录返回嵌套编码的已知密钥。
- 删除另一项 Skill / 插件不再关闭正在编辑的项目或丢弃草稿。
- 提供商、Skill、插件的更新必须携带页面原始版本；旧表单和无版本更新返回 409，防止重新启用已停用配置或覆盖他人编辑。
- 已受理但响应丢失的请求，恢复时遇到限流或超时仍保留原幂等 ID；不会因此重新创建任务。
- 步数和上下文容量上限返回明确的 409；未受理的续聊不再被当成不确定执行。
- MCP 列表读取、初始化和 DNS 等等待后重新检查配置及运行授权；取消任务后不会再启动下一次模型请求。数据库授权查询也支持取消和超时。
- 拒绝 MCP 空字段、非法类型或缺少文本的畸形结果，不能将其误标为成功；被明确拒绝、没有发送的调用不标记为远端结果未知。
- 结束任务时关闭尚未开始的动作，防止失败任务留下可误解为待执行的“已批准”状态。
- 扩充密码库路径及哈希检测，避免 `htpasswd` / `htdigest` 等凭据进入模型；Docker 诊断使用不包含 COMMAND 的固定字段。
- 修正 `nginx -t` 的只读分类，以及 systemd 间接触发单元的标准审批。可读取普通可执行文本；完全自动允许改写可执行配置，仍保留秘密与路径限制。
- 根据最新截图重新规划 AI 页面：固定视口工作区、底部输入框、桌面历史侧栏、手机历史抽屉，隐藏各内容区滚动条并保留滚轮/触控/键盘浏览；避免长对话把输入区域推到屏幕之外。

本轮不使用真实模型或插件凭据、不产生付费模型调用、不修改用户远端服务。最终完整测试和部署结果以本轮对应提交的 Actions 为准。

## 整体前端体验复查

在 AI 面板联动上线后，按共用导航、服务器与文件、运维、账户设置四个范围检查，并交叉复核修改。

- 导航：低高度桌面菜单在独立区域滚动，底部状态不再覆盖菜单；手机使用可关闭的抽屉，支持遮罩、Escape、焦点恢复及选择页面后关闭。懒加载页面期间保留导航和顶部栏。
- 告警状态：加载失败和断网明确显示未知状态，提供重试；成功读取零条告警显示“当前无活跃告警”，避免将无告警等同于所有服务器正常。取消旧请求，防止返回较晚的响应覆盖新数量。
- 运维页面：修复 320px 手机上的网络对比、备份文件输入和长名称溢出；通知中心统一留白与筛选；网络图表适配深色主题。日志时间倒序在前端提示，保留已有结果，日志区域支持键盘滚动。
- Docker 与文件：日志抽屉长标题和工具栏可换行，关闭按钮始终可操作；文件路径改为可聚焦按钮，未保存时保留锁定。
- 账户设置：凭据读取失败提供持续错误提示和重试，旧读取不能覆盖新增结果；登录历史失败保留正确页码，重试原目标页并取消旧请求；标签创建防重复提交，失败保留草稿，手机标题和操作分行；登录注册补齐输入名称和提交期间禁用。
- AI：保留桌面与手机的一屏工作区、隐藏内容滚动条及固定输入区，并纳入既有模型、审批、Skill、MCP 和任务恢复回归。

验证包含构建、ESLint、浏览器完整回归，以及 320px / 390px 手机、低高度桌面和深浅色视觉检查。新增测试覆盖导航关闭与未保存文件保护、懒加载外壳、请求竞态、失败重试及窄屏可操作性；业务请求使用模拟 API，不向真实服务器或通知渠道执行操作。最终 CI 与部署结果见对应提交的 Actions。
